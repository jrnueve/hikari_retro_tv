# hardware/

Esquemas, diagramas y notas de electrónica del proyecto: fotos del filtro RC
armado, diagrama del circuito en KiCad/Fritzing si se formaliza, datasheet o
notas del modulador de RF específico usado, y fotos del pinout de TV Out
verificado en la placa física.

La descripción textual del circuito de audio (filtro RC) y la referencia al
pin de video compuesto vive en
[docs/wiki/01_hardware_esquemas.md](../docs/wiki/01_hardware_esquemas.md).
Este directorio es para los artefactos (imágenes, archivos de diseño), no
para la documentación en sí.
